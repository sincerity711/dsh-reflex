# Reflex 页面中英文支持

Reflex 场景页使用 DSH 的客户端 locale 服务和插槽翻译能力，不增加单独语言开关。注册完整的中文和英文字典：随 DSH 语言切换更新界面文案；其他语言遵循 DSH 的回退链，缺少翻译时回退英文。日期时间随当前语言格式化。

覆盖页面标题、标签、说明、按钮、状态、空状态、保存反馈和可预期的接口校验错误。接口返回稳定的错误标识供页面翻译，同时保留原有错误文本兼容其他调用者；未知错误显示安全的英文通用说明，详细信息保留在服务端日志。会议标题、用户配置的提示词、原始字幕和模型纪要均为用户数据，不自动翻译、不修改持久化内容。

验证中文字典和英文字典的完整性、错误映射与回退；运行项目检查，并在 DSH Desktop 验证语言切换及页面状态。测试期间保留原设置并恢复用户原先语言，不影响 Teams 程序启用状态。
